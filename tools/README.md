# Инструменты для листов (для Claude)

- `hide.py лист.html` — крестик «Скрыть на сегодня» у разделов и заданий.
- `uimg.py лист.html` — «+ Своё задание картинкой» в каждом разделе.
- `site_sheet.py лист.html лист-сайт.html` — версия листа для сайта: синхронизация, общее рисование, картинки, награды из карточки.
- Готовый лист кладётся в `inbox/` и записывается в `inbox/list.json` (file, student, title, note, added).
- `firestore.rules` — текущие правила Firestore (вставляет Екатерина в консоли Firebase).
